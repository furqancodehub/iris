# 🌸 IrisAI - Premium ML Classification Platform

A luxury, billionaire-tech style machine learning web application built with Streamlit and the classic Iris dataset.

## Features
- 🏠 Professional Dashboard with real-time KPI cards
- 🤖 AI Prediction with confidence scores
- 📊 Interactive Dataset Explorer
- 📈 Advanced Data Visualizations (Plotly)
- 🧠 Multi-model Performance Comparison (5 models)
- 🔬 Explainable AI with radar charts
- 📜 Prediction history with CSV download

## Tech Stack
- Python 3.8+
- Streamlit
- scikit-learn
- Plotly
- Pandas, NumPy

## Local Setup
```bash
pip install -r requirements.txt
streamlit run app.py
